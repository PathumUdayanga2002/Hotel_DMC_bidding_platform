## 📊 Key Decisions Made

| Decision Point | Client Choice |
|---------------|--------------|
| **Registration Approval** | Manual (admin reviews before activating) |
| **Rate Negotiation** | Sequential (Wish → Want → Walk) |
| **Bidding Type** | Sealed (hotels can't see other bids) |
| **Payment Timing** | Immediate (upon booking confirmation) |
| **Commission** | 5% from hotels, collected post-stay |
| **Voucher Generation** | Auto-generated by system + emailed |
| **Supplements** | Mandatory (auto-applied) + Optional (DMC choice) |
| **Mobile Support** | Responsive web app (no native app yet) |

- **SendGrid Email:** $15/month (40k emails)
