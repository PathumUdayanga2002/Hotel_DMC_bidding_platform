## 📋 System Features Clarified

### Registration & Verification
- **Method:** Manual admin approval (not auto-approval)
- **Flow:** User registers → Pending status → Admin reviews → Approved/Rejected

### Rate Negotiation (Direct Inquiry)
- **Sequential Flow:**
  1. DMC sees Wish Rate (automatic)
  2. DMC requests better price → Hotel reviews
  3. Hotel approves Want Rate
  4. If accepted → Booking confirmed
  5. If still negotiating → Hotel offers Walk Rate (final)

### Bidding Workflow
- **Sealed Bidding:** Hotels cannot see each other's bids
- **Bid Modification:** Yes, hotels can update bids before deadline
- **Same Price:** First bidder wins
- **Auto-close:** After DMC confirms and pays

### Booking & Payment
- **Payment Timing:** Immediately upon booking confirmation
- **Voucher:** Auto-generated by system, emailed to both parties
- **Availability Confirmation:** Manual (until PMS integration)

### Supplements
- **Mandatory:** Automatically applied if dates overlap
- **Optional:** DMC can choose to include/exclude

### User Management
- **Hotel Users:** Single access level (hotel_user)
- **No Role Hierarchy:** All hotel users have same permissions

### Commission
- **Charged To:** Hotels only (not DMCs)
- **Collection:** After guest checkout (post-stay)
- **Rate:** 5% default (configurable)
- **No Subscription:** Commission-based model only

### Communication
- **In-Platform Messaging:** Yes (for negotiation)
- **Email Notifications:** Yes (vouchers, confirmations, OTPs)
- **Phone/WhatsApp:** No integration

### Search & Discovery
- **Search By:** City, star rating, amenities, price range
- **Map View:** Not required
- **Filters:** Yes (multiple criteria)

### Reviews & Ratings
- **Bidirectional:** Both DMC ↔ Hotel can rate each other
- **External APIs:** No (no TripAdvisor/Booking.com integration)
